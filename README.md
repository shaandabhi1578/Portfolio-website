## ✨ Key Features & Interactive Highlights

### 🎨 WebGL & Shader Canvas Experiences
- **Molten Metal WebGL Shader:** Custom fluid WebGL2 raymarched background shader with interactive mouse particle deformation & theme-aware color gradients.
- **Grid Distortion & Iridescence:** Dynamic 3D mesh spring distortion powered by `OGL` WebGL renderer.
- **Gradual Blur Transitions:** Smooth CSS backdrop blur gradient dividers (`GradualBlur`) between content sections.
- **Particle Text Header:** Interactive canvas text engine responding to hover/pointer inputs.

### ⚡ Data Structures & Algorithms (DSA) Visualizer
- Step-by-step interactive array algorithm visualizer (Bubble Sort / Linear Search) with real-time execution stats (comparisons, swaps, time elapsed).

### 💻 Interactive CLI Terminal Widget
- Embedded terminal simulator supporting built-in commands:
  - `resume` — Display quick contact info & qualifications
  - `about` — Background & university details
  - `skills` — Technical skills breakdown
  - `projects` — Highlighting featured C++ & Web projects
  - `certs` — Certifications from Coursera & University of London
  - `contact` — Quick links & contact details
  - `matrix` — Interactive green code stream animation
  - `clear` — Clear console buffer

### 📄 Interactive Resume Preview Modal
- High-fidelity interactive resume viewer with direct PDF download capability.

## 🚀 Quick Start & Development

Follow these steps to run the portfolio locally on your system:

### 1. Prerequisites
Ensure you have **Node.js (v18+)** installed.

### 2. Clone the Repository
```bash
git clone https://github.com/shaandabhi1578/something.git
cd something
```

### 3. Install Dependencies
```bash
npm install
```

### 4. Start Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser to view the app.

## 📦 Available Scripts

In the project directory, you can run:

- `npm run dev` — Starts the local Vite development server with Hot Module Replacement (HMR).
- `npm run build` — Bundles and optimizes the production build into the `dist/` directory.
- `npm run preview` — Locally previews the generated production build.
- `npm run lint` — Runs `oxlint` to check code for syntax and style issues.
